## 2. Tratamiento local del contenido de los usuarios

Los textos, los metadatos de las series, los episodios, las fuentes, las notas
de reflexión y las imágenes seleccionadas se procesan localmente en el
navegador. La aplicación no requiere iniciar sesión y no tiene base de datos
ni almacena estos contenidos en un servidor.

Los PDF y las copias de seguridad de los proyectos en formato `.seriescreator`
se generan localmente. Las copias de seguridad solo se crean o se leen en el
dispositivo y no se transmiten al operador de la aplicación.

## 3. Almacenamiento local

La aplicación utiliza `localStorage` para guardar en el dispositivo el idioma
seleccionado y el borrador actual. La aplicación no transmite estos datos al
operador. **Nuevo / Borrar** elimina el borrador activo y, si existe, la copia
de recuperación. Se conserva el idioma seleccionado y se crea un proyecto
nuevo. Puedes usar las funciones del navegador para borrar todos los datos
del sitio, incluido el idioma seleccionado. Si el navegador bloquea el acceso
al almacenamiento, la aplicación no puede borrar los datos allí guardados e
informa del error.

## 5. Cloudflare Web Analytics

Este sitio utiliza Cloudflare Web Analytics para analizar estadísticamente su
uso. Se pueden tratar datos sobre las visitas a las páginas, su procedencia
(referrer), el tipo de dispositivo, el navegador, la ubicación aproximada y el
momento del acceso.

Según Cloudflare, Web Analytics no utiliza cookies, `localStorage`, perfiles
que vinculen distintos dispositivos ni técnicas de identificación individual
mediante huella digital (fingerprinting) con fines de análisis. El tratamiento
se basa en el interés legítimo de analizar y mejorar el sitio web, conforme al
artículo 6, apartado 1, letra f), del RGPD.

## 6. Cookies y contenido externo

La aplicación no instala cookies publicitarias ni de seguimiento y no carga
fuentes externas. Los enlaces externos solo se abren cuando el usuario hace
clic en ellos. Cloudflare puede utilizar cookies como parte de medidas de
seguridad técnicamente necesarias.
